# 手機標記頁面

管理員入口：`/admin/annotations`。沿用既有帳號、題組、API 與伺服器進度。

| 手勢 | 健康分類 | 主張配對 |
| --- | --- | --- |
| 右滑 | 健康相關（1） | 同一主張（1） |
| 左滑 | 無關（0） | 不同主張（0） |
| 從卡片底部上滑 | 無法判斷（null） | 不使用 |

- 內文區可直向捲動；上滑第三選項只從底部滑動區開始，避免閱讀時誤標。
- 短拖動、取消手勢與直向捲動不送出答案；儲存中不接收第二次作答。
- 儲存成功才換題，失敗保留本題與備註，可重新滑動。409 沿用重新載入進度流程。
- 「更多」收納登入身分、規則與例子、分析用 JSON 匯出，以及手機點選作答選項。
  匯出僅供分析／備份，標註者不需下載檔案才算完成。
- 備註與拿不準收在補充備註視窗，隨作答一起保存；上一題可重新標記。
- 桌面保留點選與 F／J／N／U 快捷鍵。

驗證涵蓋手機 Chromium／WebKit 的左右滑、底部上滑、長文閱讀、短拖取消、
錯誤重試、備註與接續進度，並保留 admin 入口檢查。Chromium 另使用原生觸控事件
驗證捲動與 pointer capture；Playwright mobile WebKit 未提供原生 touchMove，
因此 WebKit 的拖動使用滑鼠 pointer，閱讀捲動使用內容區 scrollTop 驗證。
